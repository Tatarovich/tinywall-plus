# TinyWall+

**Простой вид. Только нужное.**

📺 **Простой лаунчер для Android 9 — в первую очередь для проекторов.**
Пять плиток, часы, погода, 11 обоев, английский и русский — без рекламы,
рекомендаций, root и перепрошивки. Разработан и обкатан в основном на проекторе
ThundeaL TD95MAX; скорее всего заработает и на других устройствах с Android 9 и
экраном 16:9.

## ✨ Что это

Многие проекторы и ТВ-боксы на Android 9 идут с вендорским плиточным лаунчером, в
котором половина экрана занята рекомендациями и сервисами. Этот лаунчер — обычное
Android-приложение, поэтому его можно заменить: без root, без своей прошивки и без
риска получить «кирпич». Вендорский лаунчер при этом не удаляется, так что вернуться
можно в любой момент.

TinyWall+ и есть эта замена: небольшое приложение на Java со стандартными View,
рассчитанное на 2 ГБ RAM. Ставится с флешки, полностью обратимо.

Ничего специфичного для конкретной модели внутри нет: это обычный лаунчер для Android 9
с экраном 16:9 и пультом-крестовиной. Разрабатывался и обкатывался он в основном на
проекторе ThundeaL TD95MAX, и скорее всего заработает на других проекторах и ТВ-боксах
с Android 9, где можно поставить APK и выбрать домашнее приложение. Такие устройства не
проверялись, поэтому первый запуск стоит считать экспериментом: вендорский лаунчер
остаётся на месте, вернуться можно за минуту.

## 🚀 Возможности

- 🧩 **Пять пустых плиток** при первом запуске, без предустановленных приложений.
  Плитка привязана к позиции 01–05; долгое OK заменяет или очищает её.
- 🗂️ **Сетка «Все приложения»**, чтобы главный экран оставался чистым.
- 🌤️ **Погода рядом с часами**: город вводится вручную, без готового списка
  (геокодинг Open-Meteo, текущие условия — wttr.in). Нужен интернет.
- 🖼️ **11 обоев** с подписями на двух языках, медленный Ken Burns, регулируемые
  затемнение и размытие (Выкл. / Лёгкое / Сильное).
- ⚙️ **Современные группы настроек** — Фон, Главный экран, Оформление, Погода —
  с крупными кнопками под пульт.
- 🔠 **Размер шрифта** Обычный / Крупный / Очень крупный, размер плиток S / M / L,
  тёмная и светлая темы.
- 📐 **Реальное разрешение экрана** в статусной строке; при смене режима интерфейс
  пересобирается под новый размер.
- 🏠 **Кнопка «Сделать домашним»**, которая открывает системный выбор HOME-приложения,
  — ADB не обязателен.

## 📥 Установка

1. Скачайте `TinyWallPlus-0.10.apk` из [Releases](../../releases/latest) и сверьте
   SHA-256 с указанным в релизе.
2. Скопируйте файл на USB-флешку (FAT32 или NTFS).
3. Вставьте флешку в проектор и откройте файловый менеджер
   («Файлы», «Медиацентр» или «Проводник»).
4. Нажмите на APK и разрешите установку из неизвестного источника.
5. Откройте **TinyWall+** и нажмите **«Сделать домашним»** → **«Всегда»**.

Подробные шаги и откат: [dist/README.md](dist/README.md).

Через ADB:

```bash
adb install -r TinyWallPlus-0.10.apk
adb shell cmd package set-home-activity ru.tihiy.dom/.MainActivity
```

Если на вашей прошивке ничего не сработало, в [docs/plan.md](docs/plan.md) разобрано
всё исследование: как устроен вендорский лаунчер, какие команды ADB это показывают
и что можно заменить без перепрошивки.

## 🌐 Веб-прототип

Интерфейс начинался с HTML-прототипа, и он до сих пор лежит в репозитории. Откройте
[`prototype/tinywall.html`](prototype/tinywall.html) в браузере — лучше всего в окне
1920×1080.

**Живая демонстрация:** <https://tatarovich.github.io/tinywall-plus/> — тот же прототип,
ничего устанавливать не нужно. Стрелки двигают фокус, Enter открывает, Esc возвращает, `S` — настройки.
Интернет не нужен.

Полезные адреса: `?lang=ru`, `?view=settings`, `?view=gallery`, `?view=tiles`,
`?view=apps&slot=0`, `?view=city&q=Moscow`, `?filled=1`.

Более ранняя версия с четырьмя сгенерированными сценами —
[`prototype/index.html`](prototype/index.html).

## 🔧 Сборка из исходников

Нужны JDK 11+ (проверено на JDK 25), Android SDK с `platforms;android-28` и
`build-tools;35.0.0`, а для импорта своих обоев — `cwebp` из пакета `webp`.
Gradle не нужен: сборка — обычный shell-скрипт вокруг `aapt2`, `javac`, `d8`,
`zipalign` и `apksigner`.

```bash
SDK=/путь/к/android-sdk bash android/build.sh
```

Без `KEYSTORE_PASS` скрипт соберёт неподписанный APK — для проверки правок этого
достаточно. Официальные релизы подписаны приватным ключом, которого в репозитории нет
и не будет.

Подробности: [android/README.md](android/README.md).

## ⚠️ Ограничения

- Вендорские **«Настройки»**, автофокус и переключение HDMI остаются вендорскими.
  Лаунчер может их открыть, но не заменит.
- Без root системные приложения не удалить — их можно только скрыть с главного экрана.
- **Обновление прошивки вернёт стоковый лаунчер**, назначение домашним придётся
  повторить.
- На прошивках, которые подавляют системный выбор HOME, для назначения может
  понадобиться ADB.
- Погода требует разрешение `INTERNET`; без сети вместо неё прочерк.

## ⚖️ Дисклеймер

Это неофициальный проект сообщества. Он не связан с ThundeaL, не одобрен и не
поддерживается компанией. «TD95MAX» и «ThundeaL» упомянуты только чтобы обозначить
устройство, на котором лаунчер разрабатывался и проверялся. К файрволу TinyWall для
Windows проект
отношения не имеет — название совпало случайно.

Установка стороннего ПО — на ваш риск. Лаунчер не трогает системный раздел,
вендорский лаунчер остаётся на месте, поэтому изменение обратимо.

## ☕ Поддержать

TinyWall+ бесплатный, под MIT, и таким останется: без платной версии, рекламы и подписок.
Если проект сэкономил вам время и хочется угостить автора кофе — вот как это можно сделать.

**RUB — перевод по номеру карты**

```
5536 9140 3935 1840
```

Виртуальная карта, выделенная только под донаты. Перевод с карты на карту. Автор —
самозанятый и платит налог с этих поступлений.

**USDT — TRC-20 (TRON)**

```
TTMmuG68drdKfthzBo4t9rY5n8QCFe917n
```

**TON**

```
UQCI5KdNl1xOzpOnepB6eho-2SzTEoNd3VKUT1XkLCoFnOzm
```

**SOL — Solana**

```
9Ud1NujZTQTsANo5hK97AZVTbWrdkP3NnypGRjDkCLgK
```

**ETH — Ethereum**

```
0x0Cb745cBb0f86ec2D5F6E1F280Df6E383A7B4f5A
```

⚠️ **Рубли — только на карту выше, никогда на крипто-адрес.** Адреса ниже — только для
крипты, каждый работает в своей сети:

- USDT в TRC-20 → на адрес TRON;
- монеты TON и жетоны на TON → на адрес TON;
- SOL и SPL-токены, включая USDT-SPL → на адрес Solana;
- ETH и ERC-20-токены, включая USDT-ERC20 → на адрес Ethereum.

Всё, что отправлено в другой сети, потеряется навсегда: сети несовместимы, вернуть
перевод нельзя.

Взамен ничего не обещаю: ни приоритетной поддержки, ни новых функций, ни обязательств.
