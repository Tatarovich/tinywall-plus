# TinyWall+ 0.10 — интерактивный прототип

Открыть: **`tinywall.html`** в браузере. Лучше всего — окно 1920×1080.
Всё локальное, интернет не нужен. Стрелки, Enter, Esc работают; мышью тоже можно.

Прототип синхронизирован с приложением **0.10**: те же пять плиток, тот же док,
тот же порядок настроек.

## Что показано

- Первый запуск: **английский**, пять **пустых** позиций, без предустановленных приложений.
- В шапке — **TinyWall+ 0.10** и реальное разрешение **1920×1080**, как в приложении.
- В доке три кнопки: **Настройки**, **Все приложения**, **Плитки**. HDMI и Source убраны —
  в 0.10 их больше нет.
- Погода **рядом с часами**. Город не выбирается из готового списка: в настройках
  открывается **поле поиска**, вы вводите название; в приложении результаты придут
  из геокодинга Open-Meteo. В прототипе результаты демонстрационные.
- **Language**: English / Русский; переключается на лету. Русский вариант — `?lang=ru`.
- **Background blur**: Off / Soft / Strong, по умолчанию Soft.
- **Dimming**: Soft / Medium / Deep, по умолчанию Medium.
- **Font size**: Normal / Large / Very large; по умолчанию Large.
- Настройки — боковая панель с группами **Background → Home screen → Appearance →
  Weather**, как в 0.10.
- **Home tiles**: пять позиций; в каждую можно назначить приложение.
  Пустая плитка на главном сразу открывает выбор приложения для этой позиции.
- 11 обоев и **Custom photo**; в прототипе «своё фото» — только демонстрация,
  в приложении открывается системный выбор файла.
- Приложение называется **TinyWall+**, версия 0.10.

## Быстрые ссылки

- Главный экран: `tinywall.html?lang=en`
- Настройки: `tinywall.html?lang=en&view=settings`
- Обои: `tinywall.html?lang=en&view=gallery`
- Позиции плиток: `tinywall.html?lang=en&view=tiles`
- Выбор приложения: `tinywall.html?lang=en&view=apps&slot=0`
- Ввод города: `tinywall.html?lang=en&view=city&q=Moscow`
- Все приложения: `tinywall.html?lang=en&view=all`
- Русский: `tinywall.html?lang=ru`
- Пример заполненных плиток: `tinywall.html?lang=en&filled=1`

## Где прототип расходится с APK

Это макет, а не эмулятор, поэтому отличия остаются сознательно:

- **Погода** — демонстрационные данные; в приложении — Open-Meteo и wttr.in.
- **Приложения** — фиксированный список с демо-запуском; в приложении — реальные
  установленные приложения.
- **«Сделать домашним»** — показывает пояснение; в приложении открывает системный
  выбор HOME.
- **Размытие** в приложении дешевле, чем в браузере: на 2 ГБ RAM полноэкранный blur
  не тянет, поэтому карточки плотнее.

## Что было раньше

До 0.10 прототип показывал шесть плиток, кнопку HDMI и индикатор Source — это
состояние 0.5. Сейчас он приведён к текущей версии приложения.
