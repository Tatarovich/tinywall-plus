# TD95MAX: можно ли заменить оболочку

> Исходное исследование, написанное до появления APK. Оставлено как история решений:
> часть вопросов в конце уже неактуальна, а устройство проверялось по близким моделям.
> Актуальное состояние — в [README](../README.md).

## Коротко

Да, оболочку заменить можно — но не «переписать прошивку», а заменить **лаунчер**. На TD95MAX стоит обычный Android 9, а плиточный экран с рекомендациями — это отдельное приложение-лаунчер. Его можно поставить другое, своё или вообще минимальное.

Полностью переписывать системную прошивку (настройки, автофокус, работу с HDMI) смысла и возможности почти нет: судя по близким моделям, это HiSilicon-платформа с закрытыми вендорскими приложениями; публичной прошивки под TD95MAX мы не нашли, а риск «кирпича» высокий. А вот лаунчер — безопасный и обратимый уровень.

## Что за устройство

- Android 9 (API 28), 1920×1080, 2 ГБ RAM / 32 ГБ ROM, Wi-Fi 6, Bluetooth 5.0.
- По близкой модели TD95W: HiSilicon + Mali-450, 2/32 ГБ, Android 9, плиточный «Smart TV»-интерфейс, Play Market и RuStore. Это данные TD95W; в TD95MAX платформа может быть другой — точный чип покажет AIDA64.
- Оболочка — вендорский лаунчер (у соседних моделей ThundeaL встречается `TvLauncher` от Zeasn) плюс вендорские «Настройки». Это не часть ядра: лаунчер — обычное Android-приложение.
- На 4PDA владельцы ThundeaL TDA7 заменяли стоковый `TvLauncher_zeasn` на Projectivy Launcher. Это подтверждает, что вендорский лаунчер у ThundeaL — обычное заменяемое приложение; на TD95MAX конкретную прошивку ещё проверим.

Источники: [официальные характеристики TD95MAX](https://thundeal.pro/td95max/), [обзор TD95W](https://mysku.club/blog/aliexpress/105303.html), [тема TDA7 на 4PDA](https://4pda.to/forum/index.php?showtopic=1093918).

## Три варианта

| Вариант | Что делаем | Время | Риск | Результат |
|---|---|---|---|---|
| **A. Готовый лаунчер** | Ставим Projectivy / FLauncher / ATV Launcher и назначаем домашним | 15–30 мин | Низкий | Сразу чище, но стиль чужой; часть функций может быть платной |
| **B. Свой лаунчер** | Пишем маленькое приложение под ваш сценарий: 5 плиток, часы, «Все приложения», настройки | 1–3 дня | Низкий | Ровно то, что нужно; без рекламы, рекомендаций и лишних сервисов |
| **C. Своя прошивка** | Разбираем образ, выкидываем стоковые приложения, вшиваем лаунчер | Дни/недели | Высокий | Можно получить кирпич; публичной прошивки под TD95MAX нет |

Рекомендация: **B**, при желании — сначала **A** как быстрый временный вариант. **C** не трогать.

## Что нужно для варианта B

1. **Установить APK на проектор.** Любым из способов:
   - с флешки через встроенный файловый менеджер;
   - через Play Market / RuStore (если есть);
   - через ADB по Wi-Fi: `adb install -r launcher.apk`.
2. **Назначить лаунчер домашним.** Это главный шаг. Варианты:
   - после установки нажать «Домой» и выбрать новый лаунчер → «Всегда»;
   - в своём лаунчере будет кнопка «Сделать домашним»: она открывает системный выбор HOME-приложения (`makeMainSelectorActivity` / `ACTION_HOME_SETTINGS`). Если вендор не подавляет этот диалог, ADB может не понадобиться;
   - через ADB: `adb shell cmd package set-home-activity <пакет>/.MainActivity`;
   - если команда не сработала — временно отключить стоковый лаунчер: `adb shell pm disable-user --user 0 <стоковый пакет>`. Это обратимо: `adb shell pm enable <стоковый пакет>`.
3. **Проверить пульт.** Нужны D-pad, OK, Back, Home. Если пульт с воздушной мышью — тоже нормально, но интерфейс проектируем под крестовину.
4. **Оставить путь отката.** Стоковый лаунчер не удаляем; ADB-доступ не теряем; перед экспериментами записываем список пакетов.

### Как включить ADB

На Android 9 обычно так:

1. «Настройки» → «Система» → «О проекторе».
2. 7 раз нажать на «Номер сборки» (Build number).
3. Появится «Для разработчиков» → включить «Отладка по USB» (если есть сервисный USB-порт) и/или «Отладка по сети».
4. На Mac: `adb connect <IP-проектора>:5555`, затем `adb devices`.

Если в вендорских настройках такого пункта нет — это не приговор, но тогда назначить домашнее приложение сложнее. Сначала проверяем, не открыт ли ADB на проекторе по умолчанию (порт 5555), и есть ли скрытое инженерное меню. Если ADB нет вообще, остаётся установка с флешки и попытка выбрать лаунчер через системный диалог «Домой» — но это сработает только если прошивка покажет такой диалог, а не оставит стоковый лаунчер по умолчанию.

### Команды для диагностики

```bash
adb connect 192.168.1.XX:5555
adb devices

adb shell getprop ro.product.model
adb shell getprop ro.build.version.release   # ожидаем 9
adb shell wm size                           # ожидаем 1920x1080
adb shell wm density

# что установлено
adb shell pm list packages -3
adb shell pm list packages | grep -iE 'launcher|home|zeasn|settings'

# кто сейчас домашний
adb shell cmd package resolve-activity --brief \
  -a android.intent.action.MAIN -c android.intent.category.HOME

# что на экране
adb shell dumpsys window | grep -E 'mCurrentFocus|mFocusedApp'
```

Эти данные нужны, чтобы понять, какие вендорские приложения отвечают за «Источник», «Настройки», «Файлы», и можно ли на них ссылаться из нового лаунчера.

## Ограничения, которые важно знать

- **Настройки и автофокус останутся вендорскими.** Лаунчер может открывать их ярлыком, но не заменит сам экран настроек. Полная замена «Настроек» — это уже уровень прошивки.
- **Переключение HDMI/AV может быть зашито в стоковый лаунчер.** Тогда в новом лаунчере делаем кнопку, которая открывает вендорский экран источника, либо оставляем переключение на кнопке пульта. Это выяснится по списку пакетов и `dumpsys`.
- **Кнопка «Домой» может быть жёстко привязана к стоковому лаунчеру.** Лечится назначением домашнего приложения через ADB или отключением стока; без ADB — не всегда.
- **Без root нельзя удалить системные приложения.** Можно только скрыть их из нового лаунчера. Это нормально: они не мешают, если их не показывать.
- **Обновление прошивки вернёт сток.** После обновления процедуру назначения лаунчера, скорее всего, придётся повторить.
- **2 ГБ RAM.** Лаунчер должен быть лёгким: без тяжёлых библиотек, анимаций на пол-экрана и фоновой сети. Поэтому предлагаю Java + стандартные View, без AndroidX/Compose, APK ~200–400 КБ.

Отличия от веб-прототипа:

- список приложений берётся из системы, пять нужных подбираются по названиям;
- если что-то не нашлось, на главном появляется «Добавить» и выбор приложений;
- кнопка HDMI пока показывает подсказку, вендорский источник не подключён.

## Как это будет в APK

- Сцены — статичные WebP 1920×1080; движение — медленный `scale`/`translate` на `ImageView`. Для 2 ГБ это дешевле, чем blur и градиентные слои.
- «Своё фото» — системный выбор файла (`ACTION_OPEN_DOCUMENT`), копия в приватную папку приложения, чтобы доступ не потерялся после перезагрузки.
- Без полноэкранного blur: на Android 9 / HiSilicon он дорогой. Карточки будут чуть плотнее, чем в веб-прототипе, иначе на пёстром фоне текст поплывёт.
- Настройки (сцена, движение, затемнение, тема, часы, размер) — в `SharedPreferences`.
- Список приложений читается через `PackageManager`; пять нужных закрепляются. Иконки — из установленных приложений.
- Кнопка «Сделать домашним» открывает системный выбор HOME-приложения; если вендор его подавляет — через ADB.

## План работ

1. Вы смотрите прототип, подтверждаете сцены/порядок приложений и присылаете фото текущего экрана + результат проверки ADB.
2. Я собираю APK под Android 9, подписываю и отдаю файл.
3. Ставим, проверяем пульт, фон, запуск приложений, возврат на стоковый лаунчер.
4. Правим то, что не понравилось, без перепрошивки.

## Что прислать

1. Фото текущего главного экрана и экрана «Настройки» (можно с телефона).
2. Подтвердить порядок шести приложений или написать свой.
3. Получается ли включить ADB (IP проектора / `adb devices`). Если нет — не страшно, попробуем через кнопку «Сделать домашним».
4. Пульт: обычный ИК/Bluetooth, с голосом, с воздушной мышью?
5. Свои фото для фона, если хотите добавить их в набор (лучше 1920×1080 или больше, горизонтальные).

## План работ

1. Вы присылаете фото текущего главного экрана, список приложений, которыми пользуетесь, и (если получится) вывод ADB-команд.

5. Если что-то не нравится — правим плитки/цвета/размеры без перепрошивки.
